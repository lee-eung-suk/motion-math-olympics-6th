# 🏃 수학 체육올림픽 (초등 6학년 2학기)

**초등학교 6학년 2학기 수학 × 체육 융합 · 모션인식 기반 웹 교육 게임**

이 학년판의 목표는 하나입니다 — **정답을 고르는 게 아니라, 온몸으로 답을 만들게 하는 것.**

`motion-math-olympics`(2학년) · `-1st`(1학년) · `-3rd`(3학년) · `-4th`(4학년) · `-5th`(5학년)와 같은 엔진을 쓰는 시리즈 작품입니다.

---

## 🎯 설계 원칙: "만드는 손"에서 "만드는 몸"으로

5학년판은 두 손으로 답을 만들게 했습니다. 6학년판은 그 범위를 온몸으로 넓힙니다.

> **서 있는 좌우 자리** = 수직선 위의 값 · 비례 분할선
> **양팔을 벌린 폭** = 반지름, **앉은 깊이** = 높이
> **당겼다 놓기** = 활시위, **점프 높이** = 스파이크 파워
> **손을 크게 휘두르기** = 3D 시점 전환

6종목 모두 온몸(MediaPipe Pose)을 씁니다. 1~5학년 중 유일합니다.

지켜야 할 세 가지:
1. **지금 몸이 만들고 있는 값을 항상 큰 숫자로** 보여 준다 (`지금 r=7, h=14 → 2154.04 cm³`)
2. **눈금 스냅** — 몸은 떨리므로 판정값은 항상 눈금 단위로 붙인다. 픽셀 정확도를 요구하지 않는다
3. **색으로 정답이 드러나지 않게** 한다. 보기 카드·풍선·과녁은 전부 같은 색·같은 모양

- **📜 룰카드**: 시작 전 캐릭터가 조작법 안내 (7초 후 자동 진행 · 건너뛰기 가능)
- **🏆 시상대 결과**: 코인이 하나씩 세어지며 ⭐별로 환산되는 결과 발표
- **🪙 파티 연출**: 코인, `굿!/나이스!/퍼펙트!` 판정, 🔥피버 타임(콤보 5마다 8초 코인 2배), 🎪관중석
- **3가지 조작 방식**: 모션인식 / 터치 / 마우스 — 어느 쪽으로도 6종목 전부 할 수 있습니다
- **자동 난이도 조절**: 3연속 정답이면 상승, 2연속 실패면 하락 (⭐ 개수로 표시)

## 🎮 6개 종목

체육과 영역은 **표적·투기 도전 & 네트형 경쟁**입니다
(3학년 속도·태그형 / 4학년 동작 도전·영역형 / 5학년 거리 도전·필드형에 이어).

| 종목 | 수학 단원 | 몸으로 하는 일 | 마우스로 못 하는 것 |
|---|---|---|---|
| 1 🏸 **분수 배드민턴** | 분수의 나눗셈 | 셔틀콕마다 분수가 하나씩 적혀 날아와요. **정답 셔틀콕만 받아치고** 오답은 아웃이니 흘려보내요 | 코트 좌우로 **달리기** + 점프 스매시 |
| 2 🎯 **소수점 클레이 사격** | 소수의 나눗셈 | 접시가 **사방에서** 날아와요. **두 손을 모아 총을 만들어** 정답 접시를 쏴요 | **두 손을 모으기** (커서는 하나) |
| 3 🧊 **쌓기나무 표적 던지기** | 공간과 입체 | 모양 카드 3장이 흘러가요. **정답 카드에 공을 던져** 맞혀요 | 던지는 **방향과 세기** |
| 4 🏐 **비례 배구** | 비례식과 비례배분 | **정답 칸 앞으로 뛰어가 서고**, 점프해서 내리꽂아요 | 코트 안 **자리 잡기** + 점프 |
| 5 🏹 **원 넓이 양궁** | 원의 넓이 | 크기가 다른 원 셋이 떠다녀요. **넓이가 곧 원의 크기.** 활을 당겨 정답 원을 쏴요 | **두 손으로 시위 당기기** |
| 6 🚀 **우주 화물 수송대** | 원기둥·원뿔·구 | 맞는 화물 앞에 서서 **앉았다 일어서서** 들어 올려요 | **스쿼트** (다리) |

각 종목은 60초 동안 진행되며 기록에 따라 동/은/금 메달이 주어집니다.
동메달 이상이면 종목 카드에 ⭐가 켜지고, 6종목을 다 모으면 🏆 종합 우승 배너가 뜹니다.

### 🕹️ 왜 모션인식이어야 하는가

5차까지의 6종목은 결국 **4종목이 "가리키고 누르기"**였습니다. 마우스로 똑같이 할 수 있으니
카메라를 켤 이유가 없었고, 종목 3은 **손을 휘둘러 돌리면 정답이 그대로 화면에 나왔습니다.**

그래서 기준을 하나 세워 전부 다시 만들었습니다 —
**"이 동작을 마우스로 그대로 할 수 있는가? 있으면 다시 설계한다."**

마우스로 원리적으로 불가능한 것은 넷뿐이라, 6종목이 이 넷을 겹치지 않게 하나씩 쓰도록 했습니다.

1. **두 손을 동시에 서로 다른 곳에 두기** (커서는 하나) — 종목 2·5
2. **동작의 세기·속도** (클릭에는 세기가 없다) — 종목 3
3. **몸 전체의 이동** (손목만 까딱하는 것과 다르다) — 종목 1·4
4. **다리 동작** — 종목 4(점프) · 6(스쿼트)

터치·마우스 모드는 카메라가 없는 교실을 위해 **대체 조작**으로 계속 지원합니다.

### 🏸 종목 1·4는 「피카츄 배구」식 실시간 랠리입니다

옆에서 본 코트, 가운데 네트, 왼쪽 상대 / 오른쪽 나. 공에는 중력이 걸린 **진짜 포물선 궤적**이 있습니다.

- **종목 1 배드민턴** — 셔틀콕마다 **분수가 하나씩 적혀** 날아옵니다. 정답이 적힌 것만 받아치고,
  오답은 **아웃이니까 치지 않고 떨어뜨립니다**(치면 상대 점수). 라켓 범위에 와도 **휘둘러야** 맞습니다 —
  그래야 "안 치는 선택"을 할 수 있습니다. **점프해서 높은 타점으로 때리면 스매시**(코인 2배)
- **종목 4 배구** — 조준은 **내가 어디에 서 있느냐**입니다. 네트 가까이 서면 짧게 앞으로,
  뒤로 물러서면 길게 뒤로. 코트에 선이 그어져 있어 눈으로 확인됩니다.
  공은 세터가 **내가 선 자리로** 올려 주므로, "공을 쫓아가는 자리"와 "겨누려는 자리"가 싸우지 않습니다
- 종목 4는 틀린 칸으로 보내면 **상대가 받아쳐 랠리가 이어집니다**(같은 문제 재도전)

### 다이나믹하게 만드는 장치 (6종목 공통)

- **판정이 끊기지 않습니다** — 판정 후 0.6초면 다음 것이 옵니다. 60초에 **8~15회**
- **연속 성공하면 빨라집니다** — 셔틀콕·접시·풍선·화물의 속도가 콤보에 따라 최대 40%까지 빨라집니다
- **마지막 10초는 라스트 스퍼트** — 속도가 더 붙고 **코인이 2배**
- **상대가 있습니다** — 종목 1은 상대 선수가 받아치고, 종목 4는 블로커가 뛰어오릅니다
- **놓치면 놓친 티가 납니다** — "놓쳤어요!" · 화면 흔들림 · 콤보 끊김
- **멈춰서 버티는 조작이 없습니다** — 예전엔 0.7~1.5초씩 정지해야 했지만 지금은 전부 **닿거나 치면 즉시** 판정

### 왜 이 조작이어야 하는가

- **종목 1**: 셔틀콕이 좌우 아무 데로나 떨어지므로 **코트를 달려야** 합니다. 그리고 라켓 범위에 와도
  휘둘러야 맞으니, **"칠 것인가 말 것인가"가 매 셔틀콕마다 판단**이 됩니다 — 아웃을 참는 것도 배드민턴 기술입니다
- **종목 4**: 조준이 **몸의 위치**라서, 답을 정하는 순간 곧바로 **그 자리까지 달려가야** 합니다.
  계산과 이동이 한 동작으로 이어집니다
- **종목 2**: 접시 셋은 **숫자가 같고 소수점 자리만 다릅니다.** 눈으로는 고를 수 없습니다.
  접시는 **아래 구석에서 솟는 포물선 · 좌우 가로지르기 · 위에서 대각선 낙하** 세 궤도로 섞여 날아옵니다.
  총알은 **세 발** — 엉뚱한 접시를 깨면 한 발 줄어듭니다(총구 관리가 게임의 일부)
- **종목 3**: 예전에는 손을 휘둘러 입체를 돌려 볼 수 있었는데, 「위에서 본 모양은?」을 물어 놓고
  위에서 본 모습으로 돌릴 수 있게 해 둔 셈이라 **돌리면 정답이 그대로 보였습니다.** 회전을 통째로 없애고,
  머릿속으로 바꿔 보는 원래의 학습으로 되돌렸습니다. 입체는 교과서처럼 **사입체(캐비닛) 투영**으로 그립니다
- **종목 5**: 예전에는 화면 가운데 **동심원 과녁**이 있고 정답은 따로 떠다니는 풍선을 쏴서 골랐습니다.
  표적이 둘이라 무엇을 맞혀야 하는지 알 수 없었고, 과녁의 점수 링은 실제 점수와 상관도 없었습니다.
  과녁을 없애고 **표적 자체를 원**으로 만들었습니다 — 원의 화면 크기가 **√넓이에 비례**하므로,
  넓이가 4배면 원이 정확히 2배 커집니다. 공식에 **숫자를 대입한 식**도 크게 띄웁니다
- **종목 6**: 화물이 무거울수록(부피가 클수록) **스쿼트를 더 해야 합니다** — 수학 값이 그대로 운동량이 됩니다.
  서서 하기 어려운 학생을 위해 **두 팔을 머리 위로 번쩍 드는 동작**도 한 번으로 인정합니다.
  화면에 `r`·`h` 대신 **반지름·높이**라고 적습니다. 5연속에 성공하면 **양팔을 벌려 몸으로 원기둥을 만드는** 보너스

## 🧒 기초학력 학생을 위한 장치

⭐1단계는 "계산은 맞았는데 조작이 어려워서 틀리는" 일이 없도록 설계했습니다.

- **생각할 시간을 줍니다** — 시작 전 2초 준비, ⭐1의 셔틀콕·공은 **3.4초** 동안 날아옵니다
- **틀려도 빨라지지 않습니다** — 속도는 *연속으로 맞힌 횟수*만 따릅니다.
  예전엔 랠리가 길어질수록 빨라져서, 실수할수록 더 어려워지는 거꾸로 된 구조였습니다
- **두 번 연속 틀리면 정답을 알려 줍니다** — 종목 1·4는 금색 화살표와 "여기예요!",
  나머지는 정답이 반짝입니다. 맞히면 꺼집니다
- **틀려도 랠리가 이어집니다**(종목 1·4) — 상대가 받아쳐서 같은 문제를 다시 시도할 수 있습니다
- ⭐1은 수를 작게 — 종목 6은 반지름 3·높이 4 이하(최대 113.04), 종목 4는 전체 12 이하,
  종목 1은 **단위분수 ÷ 자연수**(`1/3 ÷ 2`)만 나옵니다
- **조작이 서툴러서 점수를 잃지 않습니다** — 종목 3의 빗나간 공, 종목 5의 빗나간 화살,
  종목 2의 잘못 깬 접시는 벌점 없이 다시 시도할 수 있습니다. 계산은 맞았는데 조작 때문에 틀리면
  아이는 수학이 아니라 조작을 원망하게 됩니다

## 📚 단원별 학습 단계 (자동 난이도 3단계)

| 종목 | ⭐ 1단계 | ⭐⭐ 2단계 | ⭐⭐⭐ 3단계 |
|---|---|---|---|
| 1 분수의 나눗셈 | (진분수)÷(자연수) | (분수)÷(분수) |
| 2 소수의 나눗셈 | 몫이 1보다 작은 나눗셈 | (소수)÷(소수) · 접시가 빠르게 |
| 3 공간과 입체 | 층수 표 → 쌓기나무 개수 | 층수 표 → 앞·옆에서 본 모양 |
| 4 비례식과 비례배분 | 비를 간단히 한 뒤 배분 | 반대쪽(오른쪽) 구하기 |
| 5 원의 넓이 | 지름 → 넓이 | 고리(도넛)의 넓이 |
| 6 원기둥·원뿔·구 | 원기둥 + 원뿔 섞임 | 겉넓이 · 구 섞임 |

오답 선택지는 아이들이 실제로 하는 실수를 흉내 냅니다 — 소수점 자리 밀림, 원주와 넓이 혼동(`2×r×3.14`), 비를 간단히 하지 않기, 큰 원에서 작은 원 빼기를 잊기 등.

  카드마다 색이 다릅니다. 호버하면 살짝 기울며 떠오르고 빛이 스칩니다
- 상단 흐르는 띠, 배경에 떠오르는 수학 기호, 메달 진행 막대(`메달 3 / 6 종목`)
- 조작 방식·도움말은 모달 시트로 바뀌었습니다

`assets/thumb1~6.png`는 이제 **필요 없습니다** — 카드가 이모지와 색으로 구분되도록 다시 만들었습니다.
(그림을 넣고 싶으시면 `IMAGE_ASSETS.md`의 프롬프트로 만들어 카드 배경에 얹을 수 있습니다)

## 🛠 기술 스택

- **프레임워크 없는 순수 HTML/CSS/JavaScript** (빌드 과정 없음)
- **[MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe)** PoseLandmarker — wasm·모델을 자체 서버에 내장
- **Canvas 2D API** — 카메라 영상 합성 및 게임 렌더링

5학년판을 복제해 시작했고, 스쿼트·각도 판정에 필요한 `js/pose.js`만 4학년판에서 가져왔습니다.
`js/party.js`는 5학년판 것이며, **4학년판의 같은 이름 파일과는 내용이 완전히 다르므로 섞으면 안 됩니다.**

기록 키는 `n1`~`n6`, 조작 모드 세션 플래그는 `smo6_mode_shown`입니다.

## 🖼 아직 없는 그림

**GitHub 연동이 아니라 Vercel CLI 직접 배포입니다** — 푸시만으로는 반영되지 않습니다.
코드를 고친 뒤에는 반드시 이 두 가지를 따로 해 주세요.

```bash
git add -A && git commit -m "설명" && git push
npx vercel --prod
```

`vercel.json`이 없으면 **MediaPipe wasm이 로드되지 않습니다** — `.wasm` 파일에
`Content-Type: application/wasm`을 붙여 주는 설정이 그 안에 있습니다. 지우지 마세요.

## ▶️ 실행

정적 파일이므로 아무 웹 서버에나 올리면 됩니다. 로컬에서는:

```bash
python3 -m http.server 8796
```

`file://`로 직접 열면 ES 모듈과 wasm이 차단되어 동작하지 않습니다.
